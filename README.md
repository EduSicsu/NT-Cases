# Schrute Farms · clickable prototype (INDT Cases)

Built with the Wardo DS colour tokens (Wardo Light and Wardo Dark), plus Geologica and Source Serif 4. Arabic text uses Noto Sans Arabic.

- Sign in with an email that contains **manager** or **employee**. Any password works.
  - manager → full path: all farms or a single farm, forms, form detail, tasks (sheet and dialog) and workspace settings.
  - employee → limited path: own overview, my tasks and my forms, locked to Pennsylvania.
- Switch EN / PT-BR / AR in the header (AR switches to right-to-left) and light or dark with the moon/sun button.
- On bento dashboards, "Customize layout" lets you drag widgets to reorder them and change spans with 1× to 4× and ↕. The layout is saved in this browser.

Run: `npm install && npm run dev`. Build: `npm run build` (static output in `dist/`).
